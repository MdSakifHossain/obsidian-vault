# **Gnome in Arch**

⬅️ [Arch Linux](Arch-Linux.md)

> First, do a minimal Install of Arch Linux and then continue

## **Steps**

- `sudo pacman -Syu`
- `sudo pacman -S gnome gdm spice-vdagent`
- `sudo systemctl enable gdm`
- `reboot`
- Log into the system Using GUI
- Open `Settings`
- Go to `Power`
- Turn off `Automatic Screen Blank`
